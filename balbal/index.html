Nasıl çalışır

  1. Conformer kodlayıcı

    Sesi 40 ms'lik karelerle dinler.

  2. Seyrek bellek

    250 bin kayıtlık bellekten her karede yalnızca 64'ünü okur.

  3. Dil modeli

    Türkçe bir KenLM, en olası cümleyi seçer.

  4. Sentetik veri ölçekleniyor

    Modelin gördüğü 1.722 saatlik farklı sesin %69'u TTS ile üretilmiş sentetik konuşma; gerçek konuşmanın payı yalnızca %26. Gerçek kaydın az olduğu yerde sentetik veriyi büyütmek işe yarıyor.

Sınırlar

Yalnızca Türkçe

Eğitimde biraz İngilizce de vardı, ama İngilizce konuşmada iyi sonuç vermez.

Kısa kayıtlar

API istek başına en fazla 30 saniye ses yazar. Daha uzun kayıtları parçalayıp gönder.

API gecikmesi

API bir Cloudflare tüneli üzerinden sunuluyor; bu, her isteğe birkaç yüz milisaniye ekliyor. Bu yüzden modelin gerçek hızını yanıtın ne kadar sürede geldiğinden ölçemezsin; ama sunucu, modelin işlem süresini yanıttaki inference_seconds alanında döner.

No GPU needed

A minute of speech is transcribed in 0.6 seconds on a CPU.

Multiple of real time, 8 CPU cores, log scale.

How it works

  1. Conformer encoder

    Listens to the audio in 40 ms frames.

  2. Sparse memory

    Reads only 64 of its 250,000 memory slots per frame.

  3. Language model

    A Turkish KenLM picks the most likely sentence.

  4. Synthetic data scales

    69% of the 1,722 hours of distinct audio the model saw is synthetic (TTS) speech; only 26% is real. Where real recordings are scarce, scaling up synthetic data works.

Limits

Turkish only

There was some English in training, but it does not do well on English speech.

Short recordings

The API transcribes at most 30 seconds of audio per request. Split longer recordings before sending them.

API latency

The API is served through a Cloudflare tunnel, which adds a few hundred milliseconds to each request. So you cannot measure the model's real speed from how long the response takes, but the server returns the model's processing time in the response's inference_seconds field.
