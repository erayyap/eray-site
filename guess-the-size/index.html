THE REVEAL

About 15.4M
active parameters.

A Turkish Conformer with shared refinement loops, sparse acoustic memory, and a KenLM decoder. The same loop weights are reused across three passes.

What exactly counts as “active”?

We use a per-frame estimate: about 15.37M non-memory-table parameters, plus at most 23,040 retrieved memory values across three passes (4 heads × 16 entries × 120 dimensions × 3 passes). Rounded: 15.4M.

The acoustic model stores 45,368,659 parameters in total, including a memory table containing 30M parameters. Different frames can retrieve different entries, so a whole recording can touch more parameters. The small token-feedback embedding is included in the dense count for a conservative estimate. The separate, non-neural KenLM language model is not included in this neural parameter count.

This is a size comparison, not a controlled accuracy or speed comparison with Whisper. Dense model sizes: OpenAI’s Whisper documentation ↗.
